# 🧠 Memory Game 🃏

## 🌍 English | 🇧🇷 Português

### 🇺🇸 English

A **Memory Game** developed using **HTML, CSS, and Vanilla JavaScript**, optimized for **desktop** users, **focusing on improving JavaScript logic.**

## 🚀 Features  
✔️ Memory matching game mechanics  

✔️ Interactive game board with shuffled cards  

✔️ Score tracking based on moves
  
✔️ Card flip animations for a dynamic experience  

✔️ Simple yet challenging gameplay  

## 🛠️ Technologies  
- **HTML5** → Semantic structure for accessibility  
- **CSS3** → Custom styles and animations  
- **JavaScript (Vanilla JS)** → Core game functionality and logic

### 🇧🇷 Português
Um **Memory Game** desenvolvido com **HTML, CSS e JavaScript puro**, otimizado para **usuários desktop**, com **foco no aprimoramento da lógica de JavaScript.**

## 🚀 Funcionalidades
✔️ Mecânica de jogo de memória, com pareamento de cartas

✔️ Tabuleiro interativo com cartas embaralhadas

✔️ Controle de pontuação baseado no número de movimentos

✔️ Animações de virada das cartas para uma experiência dinâmica

✔️ Jogo simples, mas desafiador

## 🛠️ Tecnologias
- HTML5 → Estrutura semântica para acessibilidade
- CSS3 → Estilos personalizados e animações
- JavaScript (Vanilla JS) → Funcionalidade principal do jogo e lógica
